# Task flow, the task manager Application

A Task Manger application used to:
Add project
Add task
Add Developer
Assign Developer a project
Assign Developer multiple task in that Project
Login and Logout for Manager and Dev Roles


## Taskflow Core logic

One project can have multiple dev, but dev can have only 1 project and 1 project can  have multiple task, but task can have 1 project, 1 task per dev but 1 dev muliple task
